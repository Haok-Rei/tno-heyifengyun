# 国策与国家精神素材

`expanded/` 中的透明图标组件和 `spirit-backgrounds/` 中的底图取自用户提供的 `Ultimate-HOI4-GFX-master`，原库为 [Globvs/Ultimate-HOI4-GFX](https://github.com/Globvs/Ultimate-HOI4-GFX)。原库的 `CREDITS.txt` 记录了各素材贡献者；本项目仅复制并重新分配了所需 PNG，没有修改原库。

`src/config/artAssignments.json` 记录具体国策与国家精神的图标分配，可运行 `python scripts/assign_strategic_art.py` 在剧情新增国策后更新。
