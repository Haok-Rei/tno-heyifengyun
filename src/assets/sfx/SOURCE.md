# 界面音效来源

所用音效选自 Kenney 的 [Interface Sounds](https://kenney.nl/assets/interface-sounds) 素材包，原始许可证见 `KENNEY_LICENSE.txt`（CC0）。

| 游戏文件 | 原始文件 | 用途 |
| --- | --- | --- |
| `ui.ogg` | `click_001.ogg` | 通用按钮 |
| `focus.ogg` | `confirmation_002.ogg` | 国策 |
| `decision.ogg` | `select_004.ogg` | 决议 |
| `event.ogg` | `open_003.ogg` | 事件与超事件 |
| `error.ogg` | `error_001.ogg` | 不可执行的国策或决议 |
