# 地图操作提醒（2026-10-01）

地图视口左上角放置小型金属图标：国策、决议、顾问、法案、工作组、特色机制，以及危机临近、试卷不足、任务暂缓。地图工具栏、国策树、事件及小游戏保持原有层级；提醒及其说明窗口只属于地图层，不使用全局悬浮窗门户。

可用性取自现有条件：国策前置、互斥、隐藏及数值要求；决议可见性、费用、冷却及额外资源；顾问解锁、空位与人事法案折扣；法案150 PP；工作组容量及尚未被派遣的地区行动。特色机制使用左侧菜单同一解锁列表，优先打开路线机制，排除常驻观赏入口合一之光。

危机剩余10天以内时提示并打开决议；试卷库存低于七日基础消耗时提示并定位教育/考试法案；当前工作组任务最近两日出现暂缓报告且尚无后续成功报告时，提示并打开对应地区。更换任务后不沿用旧任务的暂缓报告。

悬停或键盘聚焦显示操作名称。左键只导航，不支付资源或执行操作。右键与 Delete 忽略当前类别30个游戏日；新增可用选项、路线变化或重新开始游戏可恢复提醒。可用性消失时清除对应忽略记录。忽略状态仅保留本轮游戏界面，不写入存档。

顾问候选人与价格抽出为共享数据，防止提醒与雇佣面板发生条件分歧。新测试覆盖隐藏与互斥国策、决议冷却/费用、顾问折扣及空位、工作组容量、特色入口状态和忽略恢复。
