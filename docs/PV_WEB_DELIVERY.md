# 《向合一奔去》PV V2 网页版本

主菜单右上角的放映机按钮打开播放器。影片保留完整的251秒、1920×1080画面和原音轨；支持拖动、全屏、原生音量控制、Esc关闭与键盘操作。打开时暂停背景音乐，片尾或关闭后恢复原先正在播放的音乐；原本暂停的音乐不会自动启动。

影片与播放库仅在点击后加载。完整源文件约760MiB，未放入发布目录；网页使用42个约6秒的独立fMP4片段，总计约143MiB，最大片段约3.64MiB，符合Cloudflare静态文件的单文件25MiB限制。播放器只提前缓冲少量片段，不在首页自动下载整片。

## 更新影片

安装ffmpeg后，在发布项目目录执行：

```powershell
./scripts/build-pv.ps1 -Source '完整的源视频绝对路径.mp4'
npm run check
```

脚本只生成`public/media/pv-v2/`下的网页派生文件及`docs/pv-v2-media.json`，保留原始视频。重新发布时提交全部片段、播放列表和封面，避免版本混用。源文件名、校验值、大小、片长和导出统计见JSON记录。

当前来源：用户制作的`TNO_向合一奔去_PV_V2.mp4`。视频采用H.264 CRF21、最高4.5Mb/s重新编码，AAC音轨直接复制；封面取自影片第32秒。

播放使用[hls.js](https://github.com/video-dev/hls.js)，Apache-2.0许可证随发布存放于`public/licenses/hls.js.txt`。支持MSE时使用hls.js，否则回退至浏览器原生HLS。Cloudflare响应类型及缓存规则见`public/_headers`。

## 核对范围

维护版本档案；未更改路线入口、时间、法案、工作组、危机或结局。播放结束和关闭不会推进游戏日期。独立浏览器检查实际1080p解码、跨段拖动、片尾、重播、音乐交接、全局音量及手机布局。
