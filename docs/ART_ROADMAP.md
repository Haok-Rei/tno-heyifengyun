# 合一风云美术接入路径

## 现有素材盘点（2026-09）

`art/` 有 82 个文件：`人像` 顶层 34 张具名图，另有 18 张身份未标明的通用头像；`载入图` 18 张；其余为及第教辅、标志和一张事件图。国策数据约 300 余个节点，原界面仅显示标题和天数；国家精神原界面仅显示名称前两个字。已具名的人像与游戏领袖、顾问存在直接对应关系。

## 本轮完成

1. **肖像资源本地化。** 为主要领袖、顾问和红蛤派系建立单一资源映射；档案身份未核实的头像统一使用“档案未公开”占位图。肖像边框、色调与暗部处理统一在 CSS 完成，原件保留在 `art/`。
2. **全树国策图标。** 国策 ID 优先使用明确映射，主要路线起始节点使用对应人物的肖像徽章，其余按标题与 ID 的语义落入十六类图标。图标框、连接线、研究中与完成状态形成同一套 TNO 风格的视觉语言。新增国策只需命名清晰，重要节点再加显式映射。
3. **国家精神图标。** 与国策共用图形体系，但按正面、负面、中性显示不同色相；悬浮说明保留现有效果数据。
4. **HOI4 图层实装。** 从用户下载的 Ultimate-HOI4-GFX 中挑选 47 张透明图层与底框接入游戏，16 类国策主题和多个剧情节点使用实际图片；国家精神也按 ID 优先选择贴切图层。国策图标由 62×49 扩大为 88×84，节点高度与纵向间距同步调整。只把选中素材打包到 `src/assets/hoi4/`，约 0.85 MB。
5. **无内框国策图标。** 根据试玩反馈，国策卡片只保留整体边框，内部改为直接显示透明图层；人物国策头像使用渐隐边缘。图层显示区域扩大到 108×92，卡片高度与树节点间距同步调整。国策图标底框原件留作后续美术参考，不在当前国策树中叠加。
