# 校园战区再编 · v9.1

本次更新保留原版的剧情、国策、决议、法案、路线小游戏与结局。地图行动成为工作组的唯一任务来源：手动和自动结算遵循同一规则。

## 开始一局

1. 在原版开始菜单选择「开始游戏」，处理开场事件。
2. 左侧主导航依次打开国家、国策、决议、编年史或菜单。国家与决议可以同时打开；点击地图地区会收起两侧面板，保留地图空间。
3. 开局在 B3、礼堂、操场可先执行少量地区行动。随着路线与国策推进，原有地区行动逐步开放。
4. 选中地区后，可按原价手动执行行动，也可指派工作组每 2、4 或 7 天重复同一行动。自动行动每次仍扣除行动原价。资源不足会延迟一天重试；路线或授权失效则撤回。
5. 地图下方显示工作组和行动电报。空格暂停或继续；事件和小游戏仍沿用原有时间流。

## 路线与工作组

- 开局有 1 组；革命阶段增加，部分分支与国策还会提供更多名额。
- 做题改革委员会沿用原有先锋党员任务。派出工作队时占用同一工作组名额，任务结束后释放；可用名额随先锋党员人数变化。
- 吕波汉清洗、豪邦公社与狗熊线的地区行动仍受原国策授权约束。杨玉乐和及第线在地图上增加了直接使用的地区行动，工作组可定期重复。
- 地图的补给图层显示原有地区控制与邻接信息，不改变行动费用。

## 资源与结算

默认法案更接近普通高压校园管理，新增「考试与试卷」及「社团与课外活动」。卷子每天按考试、作息及教育政策使用；大量囤积会产生额外库存损耗，顶栏悬浮说明列出该项。

结算页汇总校园运行天数、使用试卷、社团活动次数，并根据本局学习环境指数和时长推算 C9 与 985 录取人数。升学数据是游戏模型估算。编年史仍随结局保存，可在主菜单「结局档案」回看。

## 验证

执行 `npm run lint`、`npm test`、`npm run build`。浏览器手动检查开始菜单、两侧面板并存、地区任务、缩放按钮与结局显示。
