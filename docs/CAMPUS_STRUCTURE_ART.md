# v9.4.3 合一之光结构重绘

## 本轮修正

用户指出v9.4.2的建筑差分与细节不足，窗内陈设杂乱；本轮初稿又被指出窗框与拱石透视错位。按这些反馈继续重画，旧窗内叠加模块已撤下。

画面保留中国高中校门、两点透视、黑底细线与八类观察区域。主楼、左右翼楼、窗型、檐口、回廊、门厅、校门和门卫室组合为12类路线×3阶段；铁腕后期另依实际分支呈现。普通开局保留四层校舍，革委会早期保持开放校园，行政健康下降不画成废墟，民主与题改保留开放接待。

新绘制包括窗洞侧壁与内退玻璃、窗套、放射拱石、出挑窗台、砖石错缝、墙角石、腰线、多层檐口、柱头柱础、门卫室侧门、踏步、屋顶通风箱、检修梯和安装支架。窗内保持黑色留白，低强度暖光独立缓变，窗框不参与闪烁。

## 透视修正

原共享`at`对四角作双线性拉伸，等宽窗跨未正确随距离收缩，斜向构件也可能弯移。改为平面单应投影，子墙面、窗框、砖缝、栏杆均复用该坐标。

拱框和放射拱石使用同一拱心、起拱线与内外半径，先在墙面取样再投影。窗洞内退和窗台外挑使用`facadeDepth`，分别保留墙面与法向的消失点；屋面细部也复用此方法。远端门柱的高度按横梁投影求取，入口踏步有踏面、立面与向前投影。

新增回归测试覆盖斜线共线、远近窗跨比例、嵌套窗框共面、深度平移后两消失点、两侧窗台投影及门柱高差。全36组建筑、校门与门卫室均检查有效SVG。场景读取原有剧情状态，不增加玩法与存档字段。

## DeepSeek绘制与审阅流程

1. 直接传入用户三张参考图，先逐图分析建筑结构和细线画法。
2. 冻结多模态通用前缀，保持参考图、绘图接口和已审阅风格约定逐字一致，将每批路线任务放在末尾，按顺序请求四组、每组9份建筑方案。
3. 校对剧情含义、结构枚举与边界，再进入统一透视渲染器；对错误的封控、废墟和工厂含义进行人工修正。
4. 发送实际初稿截图进行视觉复核，修正窗洞、窗套、檐口、柱础与台阶；用户补充的透视错误由投影数学与实机截图共同检查。
5. 额外请求外部建筑构件。自动审批拦截了完整源码发送，此请求未执行；安全替代仅发送用户参考图、绘图需求与接口约定。返回代码出现交叉矩形、路线误配、覆盖窗区等问题，未原样采用；依据构件建议在本地重画。

脚本：`scripts/art/campus-study.mjs`；通用前缀拼接：`campus-context.mjs`；数据校验与调用收据：`admit-campus-profiles.mjs`。旧`director.mjs architecture`模式已停用，避免再次生成窗内杂乱叠图。模型与密钥不进入游戏运行时。
