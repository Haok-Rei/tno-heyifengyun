# v9.4.4 拱廊纵深与错峰光影

## 实机问题与修正

2026-10-20用户再次指出带拱廊场景的两翼错位、缺少体积，过去的错落光影不见了。先在独立浏览器复现，保存修复前六种场景和多个时间点的灯光。

检查发现：旧版低翼楼直接沿同一转角落下，高度乘以0.76/0.84等任意比例；左右楼层又分别均分，导致层高、腰线、拱廊开口无法接续。单个平面的投影正确并不能保证两个体量能够组成合理建筑。拱廊只有套线，缺少内壁与地面。窗灯只有0.12的填充强度，再乘0.66–1的动画透明度，亮灭几乎不可辨认。

### 建筑体量

- `campusMassing.ts`先构成共享转角的高楼两面，在两跨之后接出低翼楼，补充高度转折的墙面与接缝。
- 主楼、低翼楼共用实际层高；楼层腰线、窗洞、阳台与拱廊统一使用该标尺。低翼楼层数按整层变化，保留各路线既有外观差分。
- 重绘深拱廊：前拱、后拱、顶面、两侧壁、地面与砖缝均使用同一投影及遮罩；受光面和背光面使用克制的明暗差。
- 移除位于视平线上方却覆盖立面的屋面贴片，屋顶栏杆密度随立面长度调整。

### 动态光影

- 每间可亮灯的房间采用稳定、独立的24–44秒周期与散列相位，包含亮起、停留、熄灭和再次回光。
- 窗内使用由暗到暖的投影渐变，保留窗框、玻璃线和黑色留白；廊下地面采用独立缓变反光。
- 展示时间不依赖游戏日期。观察悬停引起的重渲染不会重新抽取随机数或重启光影。
- `prefers-reduced-motion`下改为固定的柔和灯光。
