# 《合一风云》文本编辑规范（2026-09 修订）

本文件取代旧版 `event-writing-workflow.md` 的“一套场景写法覆盖所有文本”规则。上轮改写已回退；不能把回退文本当成新范本。任何批量替换先提交少量对照稿，逐篇核对剧情和语气，再决定是否进入游戏。

## 样本的边界

外层 `文本/TNO广东国事件.txt` 的四篇可直接研究事件的视角、场景推进和按钮收束。《万家灯火》以食堂、住房与工厂的具体生活切入；《岛》从老人散步与岗哨引出历史。它们篇幅差距大，不能据此规定每篇事件的固定字数或四段模板。

`文本/TNO革命国家精神.txt` 与 `文本/TNO美国国家精神.txt` 给国家精神提供“来由—制度现状—当下后果”的短文范式；描述承担解释作用，数值效果另列。`文本/TNO领导人.txt` 虽自称官方介绍，实际上是中文二次创作式长传：可参考“个人处境映照时代”，不可据此认定游戏内人物简介都应长篇、全知、密集抒情。文本目录没有独立 TNO 新闻原文。新闻规则来自本项目现有通报、发布会等材料，属于本地编辑规范，不能冒称 TNO 原文格式。

及第线事件（`src/data/storyEvents.ts`）是本项目内部参照。其长处是让制度落在企业 LOGO、座次、合同、成绩屏、试卷与费用上；它也偶有一段内连续叠加“机器、流水线、巨兽”等意象的毛病。借具体物件和手续，不复制其过量修辞。

## 先做事实卡，再决定文本类型

每条待写内容先记录：`ID / 类型 / 路线与阶段 / 触发条件 / 玩家此时已知事实 / 视角或信源 / 必须新增的一条信息 / 选项及实际效果 / 后续承接 / UI 可容纳长度`。对照代码中的人物身份、日期、地名、数值与旗标。没有来源的伤亡、经济数字、心理动机和历史断言不能补写成既成事实。随机事件另记同主题近期出现次数和阶段差分，避免只换词重复播报。

### A. 事件与随机事件：正在发生的事

- 入口选一个可观察的动作或场所，而不是政局总结。允许人物近景或社会全景，但一篇内的视角应稳定。
- 正文须至少推进一件事：人物做了什么、制度如何改变他/她的选择，或玩家新知道了什么。短事件只需一个有效细节；重大转折才有足够篇幅铺开历史与心理。
- 对话是角色在当前处境中会说的话，不是替作者复述主题。每段最多一个主导意象；具体动作已说明代价时，删掉其后的抽象总结。
- 按钮文案承接叙事，可是回应或余音；机制效果必须在效果区清楚列出，不把尚未发生的结果写成已发生事实。
- 随机事件同时核对触发条件与阶段：同一办公桌、走廊或传单题材再出现时，必须有新的情节信息或新人物反应。

### B. 新闻、通报、广播：谁在告诉谁

- 首先确定发布者、受众、渠道和信息权限：校方公告、学生地下小报、地方媒体、广播讲话的可信范围不同。
- 标题与导语交代谁、何时、何事；正文列可核事实、具名回应和该来源的立场。争议保留归属，例如“校方称”“目击学生说”，不由全知旁白裁判。
- 官方通报可以回避信息；地下小报可以有偏见，但必须让读者看得出信源。宣传讲话单列为“广播/宣言”，不要混作客观新闻。
- 本地无 TNO 新闻原文样本。需要声称复刻 TNO 新闻文体前，先补可核来源和原文分析。

### C. 国家精神：制度的来由和后果

- 第一层解释它为何形成，第二层说明今天怎样运作，第三层指出代价或不稳定处；实际需要几层由内容决定。
- 用制度、行动与校园生活连接宏观状态。不要重说图标、名称或 buff 数字，不要把国家精神写成某个角色的一幕戏，也不要每条都以预言式金句结尾。
- 与当前路线、时间点相符；如果换线时该制度已被撤销，优先修正精神的保留条件，而不是用文案强行解释。
- 动态的“合一之光”是观赏性精神，文字描述现场状态，无正负增益。外观和普通精神一致，入口留在左侧特色机制列表。

### D. 人物介绍：可证的身份与权力处境

- 写稳定履历、做事方法、当前权力位置、支持者/反对者为何这样看他，以及一个已由剧情支持的局限。
- 人物能在游戏阶段变化，但介绍不能提前泄露后续路线；不同阶段用事实卡另写差分。
- 避免全知心理独白、空泛人格标签和每人固定“时代命运”收尾。特质、buff、debuff 放在独立 UI 区域，正文不复述数值。

## 三轮编辑，禁止直接批量覆盖

1. **资料编辑**只读四份 TXT、设定和相关代码，输出每种体裁的样本观察、事实卡、禁改清单。低成本模型可承担此轮，但必须给出可定位的文件和具体段落；无法证实的地方写“未找到”。不得让它直接批量改正文。
2. **执笔编辑**按单一类型、单一路线、单一剧情阶段写 2–4 条试稿，附旧稿与新稿对照、改动理由和事实依据。事件、新闻、精神、人物分批，不能用同一个提示词或同一篇幅模板。现有玩家认可的及第线原则上只读，除非明确指出具体需要修改的句子。
3. **校对编辑**逆向阅读：遮住标题是否还能看出体裁；视角是否知道不可能知道的事；每段是否提供新信息；删掉末段是否毫无损失；名词、数值与机制是否吻合；按钮是否暗示不存在的效果；同批是否重复开头和结尾。未过关的稿保留旧文。

**入库门槛**：先在游戏正常字号下审读试稿，检查早、中、晚阶段以及一次随机重复触发；再运行类型检查和与触发相关的测试。批量替换需在小批被接受后推进，保留逐条回退清单。不能以“字数增加”“更像 TNO”“更文学化”作为验收理由。
