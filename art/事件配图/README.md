# 事件配图目录

本批覆盖361条已编写事件，并补充内联事件与23类校园随机事务，共445条配图配置。使用现有场景、人物肖像和国策组件，不修改事件正文、选项、效果或触发条件。

## 配图方式

- 重要新闻、起义、谈判结果和结局保留对应场景CG。
- 人物交涉、任职和人物视角采用对应肖像，共34条，旁边以具体物件提示情境。
- 政策、校园事务与其他事件使用两个相关国策组件，统一置于深色档案插图背景。114条事件可关联触发国策的美术；具体选择还结合事件标题和内容。
- 缺少合适场景的宿舍夜话、医务室恢复、午夜天台邀请补绘三张插画。PNG源图、提示词和画质检查记录在`2026-10-11`内；网页使用1200×800 WebP。

445条配置中有443种不同的场景或主体组合。这是组合数量，并非443幅新CG；已有组件可以在不同情境中再次使用。同一校园事务不同阶段共用该事务的主体；未知旧存档事件保留原有图片后备机制。

## 后续维护

1. `src/config/eventArtBindings.json`保存逐事件配置；运行时由`eventArtwork.ts`解析本地素材。
2. `scripts/assign_event_art.ts`的`specific`表维护明确的人物和场景对应。新增关键事件优先在此指定。
3. 在项目根目录运行`npx tsx scripts/assign_event_art.ts`，可重新整理事件配置和本目录的`assignments-report.json`，无需外部服务。
4. `EventIllustration.tsx`处理完整肖像、图标组合和场景三类显示；旧图标的黑色底色通过混合模式融合，避免方块背景。
5. 新图沿用`repair-ai-image-quality`默认检测：两张清理规则网格，一张检测后原样保留；不强制模糊干净细节。
